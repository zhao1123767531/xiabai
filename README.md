# 瞎掰王

一个面向聚会场景的网页游戏原型。玩家创建或加入房间后，系统每轮分配 1 名老实人、1 名大聪明，其余玩家为瞎掰人。老实人知道生僻词真实释义，其他玩家只能一本正经地瞎掰，最后由大聪明验证最可信的人并结算分数。

## 本地预览

```bash
npm run dev
```

然后打开 `http://localhost:4173`。

当前代码是前端单机原型。为了方便单设备走完整流程，可以打开 `http://localhost:4173/?demo=1`，此时会出现演示用的玩家视角切换能力。正式联机版本不应暴露该能力。

## 规则状态

- 人数限制：至少 4 人开始，最多 12 人。
- 身份分配：1 名老实人、1 名大聪明，其余为瞎掰人。
- 身份可见性：老实人身份公开，其他身份仅本人可见。
- 释义查看：只有老实人看到真实释义，其他人看到“不知道释义”的提示；释义弹窗 10 秒后关闭。
- 方向提示：每道题展示 3 个候选方向，只有老实人和揭晓阶段会标出正确方向。
- 换题：老实人可在讨论阶段发起换题，二次确认后更换本轮题目并重置释义查看状态。
- 记分：大聪明押中老实人时，大聪明和老实人各 1 分；大聪明押中瞎掰人时，被押中的瞎掰人 1 分。
